## 桥接实测

| 接口 | 实测结果 | 状态 |
|---|---|---|
| `/scan` | `LaserScan`，BestEffort/Volatile，`laser_link`，时间戳非零，约9.995 Hz，角度范围±π，最大距离12 m | 通过 |
| `/camera/image_raw` | `Image`，BestEffort/Volatile，`camera_optical_link`，时间戳非零，320×240，`rgb8`，约15.14 Hz | 通过 |
| `/camera/camera_info` | `CameraInfo`，BestEffort/Volatile，`camera_optical_link`，320×240，3×3内参矩阵有效 | 通过 |
| `/imu/data` | `Imu`，BestEffort/Volatile，`imu_link`，时间戳非零，姿态/角速度/线加速度有效，约99.9 Hz | 通过 |
| `/joint_states` | `JointState`，由`joint_state_broadcaster`发布，包含左右轮位置与速度，时间戳非零，约100 Hz | 独立入口通过 |

原始Gazebo Topic使用`/sim/...`命名，`ai_robot_sensors/sensor_adapter`统一改写Frame并以ROS 2传感器QoS发布公共接口。`lidar.launch.py`、`camera.launch.py`、`imu.launch.py`和`encoder.launch.py`可分别启动。编码器默认契约见`config/encoders.yaml`，仿真位置是连续弧度值，2048 ticks/rev作为后续实体适配和量化测试基准。
