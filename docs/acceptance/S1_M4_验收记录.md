## 初始契约

- 坐标树保持`map -> odom -> base_link -> sensor_link`，M4不允许重复发布`odom -> base_link`。
- 仿真时间域内的融合、TF和传感器消息必须使用一致时钟，不得以墙钟替代数据时间戳。
- 上层继续使用`/cmd_vel`、`/odom`、`/scan`、`/imu/data`和`/diagnostics`，不感知`sim|real`底层差异。
- 故障注入必须可恢复且不得绕过命令超时、速度限制或底层失联保护。
