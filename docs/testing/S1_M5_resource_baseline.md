# S1-M5导航资源与性能基线

- 场景：`navigation.launch.py mode:=sim`，完整地图、AMCL、Nav2、Gazebo、传感器、EKF和安全链
- 采集入口：`scripts/measure_m5_resources.py`
- 采集窗口：生命周期启动后预热20秒，连续采样30秒
- 安全约束：只发送零速度延迟探针，不产生机器人运动
- CPU口径：完整launch进程树的多核累计CPU，因此允许超过100%
- RSS口径：完整进程树RSS之和，不等同于独立进程私有内存之和

## 冻结阈值

| 指标 | 阈值 |
|---|---:|
| 进程树CPU P95 | ≤ 800% |
| 进程树RSS P95 | ≤ 1800 MiB |
| `/odom` | 24–36 Hz，新鲜度P95 ≤ 60 ms |
| `/scan` | 8–12 Hz，新鲜度P95 ≤ 60 ms |
| `/global_costmap/costmap` | 0.6–1.3 Hz，新鲜度P95 ≤ 1500 ms |
| `/cmd_vel`至控制器零速度探针延迟P95 | ≤ 50 ms |
| 完整地图几何 | 244 × 204格 |

阈值固化在采集脚本中；数据缺失或任一指标越界时返回非零退出码。CPU和RSS阈值是当前开发机的软件仿真回归门槛，不代表实体机器人硬件需求。

## 两次实测

| 指标 | 首次 | 复测 |
|---|---:|---:|
| CPU P95 / 最大值 | 700.91 / 711.83% | 653.78 / 656.95% |
| RSS P95 / 最大值 | 1644.97 / 1644.97 MiB | 1650.91 / 1650.91 MiB |
| `/odom` | 29.81 Hz，10 ms | 29.94 Hz，10 ms |
| `/scan` | 9.93 Hz，12 ms | 9.98 Hz，9 ms |
| 全局代价地图 | 0.667 Hz，1 ms | 0.678 Hz，1 ms |
| 命令链延迟P95 | 26.96 ms | 26.11 ms |
| 地图几何 | 244 × 204 | 244 × 204 |
| 判定 | 初始0.7 Hz下限过紧 | PASS |

首次采集只有全局代价地图0.667 Hz略低于预设0.7 Hz；结合配置目标1 Hz和两次稳定分布，将下限冻结为0.6 Hz后复测通过。没有为了通过而修改运行时Nav2频率。

## 导航质量阈值

同一轮专项launch测试同时冻结：最大到点角度误差小于0.50 rad、单段导航少于100秒、三段总耗时少于240秒、规划路径到雷达已观测临时障碍表面的最小距离不少于0.35米。

四次角度采集分别得到最大残差0.309、0.410、0.435和0.421 rad，因此阈值按多次分布冻结为0.50 rad；首轮0.35 rad门槛未被错误记录为通过。代表性路线三段耗时26.532、35.131、34.662秒，总耗时96.326秒；最终确认轮三段25.202、30.531、26.991秒，总82.725秒。路径到已观测障碍表面的最小距离0.450米。这里的障碍净距是对雷达已观测表面的规划路径指标，不是独立真值系统测得的机器人外壳物理净距。

